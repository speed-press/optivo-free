Extra fields on WooCommerce products. Text, email, number, dropdown, radio, checkbox, and headings. No license required.

== Description ==

Optivo – Product Options for WooCommerce lets a store add extra fields to a product page. Customers fill them in before the product is added to the cart.

Every feature in this plugin works immediately. There is no license key, no trial, and no locked feature.

= Field types =

* Text
* Textarea
* Number
* Email
* Dropdown
* Radio
* Checkbox
* Heading
* Paragraph

Each input field can add a fixed price, a percentage of the product price, or a price multiplied by quantity. Prices are calculated again on the server when the product is added to the cart.

= Where the answers are stored =

Cart, checkout, the order screen, the customer account, and order emails.

= Where you add the fields =

* On one product: edit the product and open the Product Options tab
* On many products: create a global group and choose which products, categories, or tags it applies to

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it. WooCommerce must already be active.
3. Edit a product and open Product Options, or create a global group from the plugin menu.

== Frequently Asked Questions ==

= Does this plugin need an API code or a paid license? =

No. The plugin is complete as distributed. It does not call an outside server.

= Does this replace product variations? =

No. Use variations for size or color attributes. Use this plugin for extra questions, such as a gift note or an email address.
